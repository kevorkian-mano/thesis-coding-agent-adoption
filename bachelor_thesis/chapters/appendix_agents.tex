\chapter{Agent Detection Catalogues}
\label{app:agents}

This appendix lists the AI coding agents and detection signal patterns from two sources used in this study. Section~\ref{app:paper-agents} reproduces the agent catalogue from Robbes et al.~\cite{robbesAgenticMuch2026}, which defines 196 heuristics across 63 agents. Section~\ref{app:e2e-agents} lists all agents and patterns from the trace pack of the e2e detection tool (version 2026-10-19), which covers 67 agents across five signal channels. The two catalogues share 61 agents; the e2e tool adds 6 agents released after the paper's data collection period (Abacus~AI, Kimi~Code, OpenCode, Letta~Code, Mistral~Vibe, Crush) and reclassifies two paper entries (CopilotSwe and Factory~Droid are merged into Copilot and Factory respectively).

\section{Robbes et al.\ (2026) --- 63-Agent Signal Catalogue}
\label{app:paper-agents}
% -------------------------------------------------------

The paper defines four signal categories across 63 agents: \textbf{Files} (93 patterns), \textbf{Authors} (79 patterns), \textbf{Branches} (20 patterns), and \textbf{Labels} (4 patterns). Full heuristics are available in the replication package~\cite{agentImpactRepo}. Agents whose exact patterns are not stated in the paper text are marked ``see replication package.'' All 196 heuristics together represent what the paper calls a \emph{frozen} catalogue: every repository in the paper's corpus was scanned with the same version.

\section{E2E Tool Trace Pack (v2026-10-19) --- Signal Catalogue}
\label{app:e2e-agents}
% -------------------------------------------------------

The trace pack shipped with the e2e detection tool (version 2026-10-19) covers 67 agents across five signal channels. \textbf{Config} patterns match files and directories in the repository tree. \textbf{Author} patterns match commit author names, committer identities, and email addresses appearing in commit trailers (\texttt{Co-authored-by:}, \texttt{Generated-by:}, and related trailer tokens). \textbf{Branch} patterns match the head-ref name of pull requests. \textbf{Label} patterns match GitHub PR labels. A sixth channel, \textbf{Bot}, covers approximately 86 CI and dependency-update automation accounts (dependabot, renovate, github-actions, etc.) that are recorded separately and excluded from adoption counts; those are not listed here. The commit ratio and binary adoption label are derived from the author, trailer, and PR-metadata channels only; config and branch channels contribute supporting evidence but do not directly affect the ratio.

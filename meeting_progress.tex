  \textit{Bachelor Thesis: AI Coding Agent Adoption in Software Repositories --- Malek Rowaizak, GIU}

\bigskip

\begin{enumerate}[leftmargin=*, label=\textbf{\arabic*.}]

  \item \textbf{Complete Visualisation Dashboard (6-Stack Ready).}
  An interactive cross-stack Streamlit dashboard is built and live with TypeScript/JavaScript (60,129 repos, 75.1\% adoption) and Java (5,290 repos, 48.3\% adoption), covering 25+ charts across overview, agents, geography, time series, size, and commit-depth tabs; the architecture accepts any new stack as a single CSV drop-in.

  \item \textbf{Solid Shared Applied Methodology.}
  A validated five-stage pipeline (corpus construction, owner geolocation, 3-pass agent detection, core analysis, extended analysis) runs identically across all stacks, with each stack contributing 2--3 ecosystem-specific edge insights---for example, the TS/JS npm/pnpm ecosystem split and the Java Maven-vs-Gradle adoption gap.

  \item \textbf{Introduction, Literature Review, Methodology, and Results Written.}
  All four core thesis chapters are drafted, covering the motivation and research questions, the AI coding agent landscape and related work, the full shared pipeline design, and the cross-stack results including geography, pricing by income group, adoption timing, and commit-density analyses.

\end{enumerate}
